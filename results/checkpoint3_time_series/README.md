# Checkpoint 3 time-series results




This folder contains Person 3's original one-year-ahead ZHVI growth experiment:




- `metrics.csv` — validation and test metrics for the growth-target experiment.
- `predictions.csv` — observed target growth and model predictions by county and quarter.
- `test_by_quarter.png` — a visualization of test-period predictions by quarter.




Person 4's separate time-series model-comparison outputs are stored in [`results/checkpoint3_model_compare/time_series/`](../checkpoint3_model_compare/time_series/). The analyses use different model specifications and produce separate outputs, so their files are kept in separate folders.

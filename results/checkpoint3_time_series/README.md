# Checkpoint 3 time-series results

This folder keeps the original one-year-ahead ZHVI growth experiment (the existing `metrics.csv`, `predictions.csv`, and `test_by_quarter.png`) together with the earlier pooled level-model experiment. Files prefixed `level_experiment_` are from that separate level-target analysis; the ARIMA/ARIMAX order-selection tables describe its validation search. These artifacts are exploratory and should not be mixed with the final growth-target comparison in `results/checkpoint3_model_compare/`.
